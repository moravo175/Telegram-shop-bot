# 🤖 ربات فروشگاه فایل تلگرام

ربات کامل فروشگاه فایل با PHP، درگاه زرین‌پال، و پنل مدیریت پیشرفته.

---

## 📁 ساختار پروژه

```
telegram-shop-bot/
├── bot.php                    ← نقطه ورود اصلی (Webhook)
├── config.php                 ← تنظیمات ربات
├── database.php               ← کلاس دیتابیس
├── zarinpal.php               ← کلاس درگاه زرین‌پال
├── helpers.php                ← توابع کمکی + BotCore
├── setup.php                  ← راه‌اندازی اولیه (بعد از نصب حذف کن)
├── database.sql               ← اسکریپت SQL دستی
├── handlers/
│   ├── UserHandler.php        ← هندلر کاربران
│   ├── AdminHandler.php       ← پنل مدیریت ادمین
│   └── PaymentHandler.php     ← callback زرین‌پال
└── uploads/                   ← پوشه آپلود (اختیاری)
```

---

## 🚀 مراحل نصب

### ۱. پیش‌نیازها
- PHP 8.0 یا بالاتر
- MySQL 5.7 یا بالاتر
- HTTPS (الزامی برای Webhook تلگرام)
- cURL فعال در PHP

### ۲. تنظیم config.php

```php
define('BOT_TOKEN', 'YOUR_BOT_TOKEN_HERE');    // توکن ربات از @BotFather
define('BOT_USERNAME', 'your_bot_username');    // یوزرنیم ربات (بدون @)
define('ADMIN_IDS', [123456789]);               // آیدی عددی خودتان
define('WEBHOOK_URL', 'https://yourdomain.com/bot.php');

// دیتابیس
define('DB_HOST', 'localhost');
define('DB_NAME', 'telegram_shop');
define('DB_USER', 'your_db_user');
define('DB_PASS', 'your_db_pass');
```

### ۳. ایجاد دیتابیس
روش اول - خودکار (توصیه شده):
```
https://yourdomain.com/setup.php
```

روش دوم - دستی:
```bash
mysql -u root -p < database.sql
```

### ۴. تنظیم Webhook
به آدرس زیر بروید:
```
https://yourdomain.com/setup.php?action=set_webhook
```

### ۵. پاک کردن setup.php
بعد از نصب این فایل را حذف کنید!

## 💳 راه‌اندازی زرین‌پال

### دریافت Merchant ID
۱. وارد پنل زرین‌پال شوید: [my.zarinpal.com](https://my.zarinpal.com)
۲. از بخش تنظیمات، Merchant ID خود را کپی کنید

### تنظیم از طریق ربات
ادمین در ربات:
```
💳 تنظیمات درگاه → 🔑 تنظیم Merchant ID → [paste]
🟢 فعال کردن درگاه
```

### تست با Sandbox
برای تست پرداخت قبل از راه‌اندازی واقعی:
```
💳 تنظیمات درگاه → 🧪 فعال کردن Sandbox
```
در حالت Sandbox از کارت تستی زرین‌پال استفاده کنید.

## 🔧 امکانات

### پنل مدیریت ادمین
| امکان | توضیح |
|-------|-------|
| 📁 افزودن فایل | آپلود فایل با نام، توضیحات، قیمت |
| ✏️ ویرایش فایل | تغییر نام، قیمت، توضیحات |
| 🔴/🟢 فعال/غیرفعال | کنترل نمایش فایل در فروشگاه |
| 🗑 حذف فایل | حذف کامل فایل |
| 👥 مدیریت کاربران | مشاهده اطلاعات، مسدود/رفع مسدودی |
| 📊 آمار | درآمد، تعداد کاربر، فروش |
| 📋 تراکنش‌ها | لیست کامل پرداخت‌ها |
| 📢 پیام همگانی | ارسال پیام/عکس/فایل به همه |
| 💳 درگاه زرین‌پال | تنظیم Merchant ID، فعال/غیرفعال، Sandbox |

### امکانات کاربر
| امکان | توضیح |
|-------|-------|
| 🛒 فروشگاه | مشاهده فایل‌ها با صفحه‌بندی |
| 👛 کیف پول | موجودی + شارژ از طریق زرین‌پال |
| 📦 خریدهای من | لیست و دانلود فایل‌های خریداری‌شده |
| 💳 پرداخت آنلاین | هدایت به درگاه زرین‌پال |

---

## 🌊 جریان پرداخت زرین‌پال

```
کاربر → شارژ کیف پول → ربات درخواست به زرین‌پال ارسال می‌کند
→ لینک پرداخت دریافت می‌شود → کاربر پرداخت می‌کند
→ زرین‌پال به WEBHOOK_URL?payment_callback=1 ریدایرکت می‌کند
→ ربات تأیید می‌کند → کیف پول شارژ می‌شود
→ کاربر نوتیف دریافت می‌کند
```

---

## ⚠️ نکات مهم

- **HTTPS الزامی است** — تلگرام بدون SSL وبهوک را نمی‌پذیرد
- فایل `setup.php` را پس از نصب **حذف کنید**
- Merchant ID زرین‌پال را فقط از طریق پنل ادمین ربات تنظیم کنید
- برای Production حالت Sandbox را **غیرفعال** کنید
- `ADMIN_IDS` در config.php آیدی عددی است (از `@userinfobot` بگیرید)
